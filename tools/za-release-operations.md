# ZA release operation

Scope: the `cowinmagnet.co.za` repository and the Vercel project for that domain.

- The public enquiry API returns success after the enquiry and any complete upload are committed together. Uploads use 1 MiB request parts (8 MiB per file maximum). An authenticated attachment URL always downloads as a file. The notification links to that private record. Abandoned upload tokens expire after 45 minutes; the cron removes expired, unclaimed uploads.
- Production mail requires a verified `INQUIRY_NOTIFICATION_FROM` and a server-only `RESEND_API_KEY` with send and receipt-read access. The destination is `info@cowinmagnet.com`, with `[cowinmagnet.co.za]` in the subject. An API message ID means accepted, not delivered. The admin receipt check and daily retry job read the provider's latest event. A failed or ambiguous attempt remains visible on the enquiry. Do not reset a provider receipt or manually resend a record marked for review until the provider's records have been checked.
- Standard admin ranges use South Africa time. The end date includes the complete selected day. Visitor and channel charts use the same exclusions; conversion is the share of observed sessions containing a form submission.
- Product editing is for detail intro and search copy. Save a draft, then publish the saved revision. A stale revision returns 409. Published copy is cached separately from drafts; allow up to five minutes for the public CDN. Model configuration, media, and URL changes still go through the reviewed release workflow. There were no verified numerical specifications or model drawings in the bundled source snapshot.
- Team roles are enforced on the API. Staff accounts only become usable when their matching salted credential has been installed in `ADMIN_TEAM_CREDENTIALS`. This does not change the primary administrator. Restrict CSV and attachment downloads to staff who handle customer records.
- Monday Google jobs are 04:00 and 04:20 SAST. A sitemap submission receipt, Google reading the sitemap, URL inspection, and actual index coverage are separate evidence. Retriable inspection errors are retried without discarding prior successful results. News automation stays paused; the Blog webhook still handles signed third-party posts and records the last confirmed receipt.
- Back up the ZA database using the database provider's recovery workflow before any destructive data operation. This release uses additive tables and leaves existing leads in their current store. A code rollback uses the previous READY Vercel deployment; it does not delete enquiries or reset mail receipts. Keep the new tables if rolling back the app. A repository revert is a separate action.
- Run `node --test tools/*-test.mjs`, then `next build`. The integration test `tools/za-release-integration.mjs` requires a dedicated loopback `cowin_za_qa` PostgreSQL database, a local production build, and a simulated email provider. It deliberately rejects non-loopback hosts. Keep both production secrets and any real customer data out of this test environment.
